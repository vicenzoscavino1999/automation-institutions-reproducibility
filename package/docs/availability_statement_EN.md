# Code and materials availability statement

The reproducibility package contains the code, synthetic configuration, frozen numerical references, exact finite-check oracles, dependency locks, platform recipes and document source required to reproduce the reduced two-date example associated with manuscript v22. No confidential, proprietary or personal microdata are used.

The package does not contain the full manuscript and does not claim a numerical solution of the parent HANK–New Keynesian model. Manuscript correspondence can be checked only when the user separately supplies the identified v22 LaTeX source whose SHA-256 is registered in config/book_claims.json.

The GitHub Actions workflow is prepared but has not been executed remotely. Version 0.1.2 produces and tests a local archive; no public repository, archival deposit, DOI or public release is asserted. Rights and third-party licensing are described in LICENSE_STATUS.md and THIRD_PARTY_NOTICES.md.
